# 동적 라이브러리 빌드

Qt와 독립적인 Markup 및 Native 구성 요소는 기본적으로 공유 라이브러리로
빌드하며 `BUILD_SHARED_LIBS=OFF`로 정적 빌드를 선택한다. 공개 CMake 타깃은
유지하고 Windows DLL, iOS 프레임워크, WebAssembly 사이드 모듈을 지원한다.
Python 행렬 브리지는 필요한 Native 라이브러리를 같은 설치 위치에서 찾는다.
플랫폼별 libxml2와 필요한 런타임은 앱 패키지에 포함해야 한다.

대상 유형, 연결 정보와 XML·행렬 기능을 검사한다. 이 검사는 앱 실행이나
플랫폼 기기에서의 동작을 뜻하지 않는다.

Emscripten 소비자 설정은 공유 사이드 모듈을 가져오기 전에 CMake의 공유 라이브러리 지원을 활성화한다. 앱의 메인 모듈 컴파일·링크 옵션은 빌더 또는 앱이 지정해야 한다.
